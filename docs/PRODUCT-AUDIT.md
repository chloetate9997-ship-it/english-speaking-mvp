# 产品问题审计与优先级

目标用户：能够阅读或听懂基础英语，但缺少真实开口场景、即时反馈和持续复习路径的成人学习者。

核心闭环：课程输入 → 复述输出 → AI 情景迁移 → 个性化反馈 → 薄弱表达复习。

## P0：上线和面试演示前必须解决

| 问题 | 用户影响 | 验收标准 |
|---|---|---|
| lesson-01 演示音频尚未提供 | 精听入口只能展示错误态，课程输入闭环不完整 | 使用有合法权利的原创或授权音频；播放器可整篇/分段播放，时间轴与 5 段文本一致 |
| 线上 RAG 尚未真实回填 | Agent 无法稳定取得课程知识，核心卖点无法证明 | Vercel 调用同步接口首次 `updated: 8`、再次 `updated: 0`；检索前 3 条均属于 `lesson-01` |
| Agent 全链路未在生产环境验证 | 面试官可能遇到 401/502/空反馈 | 登录后连续完成 3–5 轮，生成报告且 Supabase 有 session/turn/progress 数据 |
| 真机录音未验收 | 手机端最关键输入方式可能因权限或格式失败 | iOS Safari 与 Android Chrome 至少各完成一次授权、录音、回放、提交和失败重试 |
| Agent 目标表达推进一致性待验证 | 页面显示的目标、服务端评估目标可能不一致，反馈失去可信度 | retry 保持当前表达；continue 才切换下一表达；页面、Prompt、落库 ID/文案一致 |

已完成：代码已发布到 GitHub，Vercel Production 链接可访问；Supabase Site URL 与登录回调已配置并完成一次线上邮箱登录。

## P1：显著影响作品说服力

| 问题 | 产品判断 | 改进方案 |
|---|---|---|
| 只有 lesson-01 完整 | 能证明闭环，不能证明内容规模化 | 再补 2 篇不同场景课程，验证数据驱动而非硬编码 |
| 未登录用户进入 Coach 的价值提示较弱 | 用户先遇门槛，可能不知道为什么登录 | 展示 3 步体验预览、隐私说明和明确登录按钮 |
| 评分缺少可解释证据 | 四个数字容易被认为是模型随意打分 | 每个维度显示一句证据或引用用户原句 |
| 学习记录未突出 Agent 进步 | 用户看不到长期价值 | 历史页增加练习次数、掌握表达、待复习表达和趋势 |
| RAG 价值对普通用户不可见 | 技术亮点难以转成产品价值 | 用“基于本课内容反馈”轻量标识，不展示技术术语 |
| 错误恢复依赖用户重试 | 服务恢复后仍需重复操作 | 保留文字/录音草稿，显示错误类型和建议重试时间 |

## P2：后续迭代

| 方向 | 价值 | 建议指标 |
|---|---|---|
| 间隔复习 | 将一次练习变成长期掌握 | 7 日复习完成率、表达二次通过率 |
| 发音反馈 | 补齐口语产品的重要维度 | 录音完成率、发音建议采纳率 |
| 难度自适应 | 降低挫败，提高连续练习 | 单表达重试率、完成一场练习比例 |
| 更多情景和课程 | 提升留存与可扩展性 | 每周练习场景数、课程完成率 |
| 实时语音模式 | 提升沉浸感，但成本与复杂度高 | 对话时长、延迟、单次练习成本 |

## 面试演示成功标准

1. 30 秒内说明用户痛点与学习闭环。
2. 2 分钟内从课程进入 Coach，完成至少两轮文字或语音练习。
3. 能解释一次反馈如何使用课程 RAG、目标表达和历史表现。
4. 主动说明隐私、成本、错误降级和 MVP 边界。
5. 展示可访问的 Production 链接，并用手机完成一次录音。
